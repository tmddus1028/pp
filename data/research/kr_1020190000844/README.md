# 한국 Patent Review 전환 가능성: 실제 문서 조사

조사일: 2026-09-16. **한국 도메인 시제품 개발을 시작할 실제 자료를 확보했다.**
사용자가 제공한 의견제출통지서와 같은 출원의 공개 명세서·청구항, 인용발명 3개의 PDF를
직접 내려받아 대조했다. 현재 서비스가 한국어 분석을 이미 지원한다는 뜻은 아니다.
이번 작업은 조사와 호환성 확인이며 `backend/`, `frontend/`는 수정하지 않았다.

## 2. 실제로 같은 사건·청구항인가

- XML과 공개공보의 출원번호, 발명의 명칭, 출원인이 일치한다.
- [공식 KIPRIS 상세정보](https://www.kipris.or.kr/khome/detail/newWindow.do?applno=1020190000844&right=kpat)의
  행정이력에도 **2019-04-09 의견제출통지서 / 9-5-2019-0256824-92**가 있다.
  구분기호를 제외하면 XML의 발송번호와 정확히 같다.
- KIPRIS 이력에 공개일 2019-03-12부터 해당 통지일 사이 보정 제출은 기록되어 있지 않다.
  이전에는 1월 15일 출원서등 보정, 3월 6일 직권정정안내서가 있으며,
  이후 8월 9일 명세서등 보정서와 의견서가 있다.
  원 응답과 추출 이력은 [version/kipris-prosecution-history.json](version/kipris-prosecution-history.json)에 보존했다.
- 공개공보 청구항 1의 **전제부 + 구성요소 7개**를 XML의 `다. 구성의 대비`와 비교했다.
  공백·구두점·심사관의 구성 번호 등을 제외하면 **8개 부분 모두 문자 일치**한다.
  원문과 비교 결과는 [claim_oa_comparison.json](claim_oa_comparison.json)에 보존했다.

따라서 이 사례는 한국어 문서 연결과 분석 개발에 사용할 대응 자료로 판단한다.
다만 원래 제출된 명세서 및 모든 보정서 원문을 확보해 바이트 단위로 검증한 것은 아니다.
행정이력만으로 과거 문서 전문의 동일성을 자동 판정하지 않는다.
등록공보의 현재 청구항을 과거 통지서에 연결하면 실제로 다른 문구가 섞이므로 버전 구분은 필요하다.

## 3. 이 자료로 표시할 수 있는 결과

원문에 명시된 기대값은 **심사 대상 청구항 1, 지적 대상 청구항 1,
관련 법조항 특허법 제29조제2항, 인용발명 3개**다.
통지서에는 구성요소별로 각 인용발명의 청구항·문단을 대조하는 설명도 들어 있다.
따라서 한국어 청구항 → 거절 사유 → 인용발명 → 원문 근거의 연결 화면을 만들 자료가 있다.
이 값은 사람이 문서를 대조한 기대값이며 기존 프로그램의 한국어 분석 성공 결과가 아니다.

대상 명세서와 인용발명 PDF는 확보했지만 **의견제출통지서의 원본 PDF는 확보하지 못했다.**
다만 [특허청 OPD 심사 문서 목록](https://kopd.kipo.go.kr:8888/viewFamilySearchResult.do?paramType=A&cntry=KR&appno=20190000844&code=A&docgrp=ALL&from=K)에서
해당 통지서의 PDF 원문 링크와 이후 의견서·명세서 보정서 링크를 확인했다.
OA 원문 클릭 후 CAPTCHA 확인이 요구되어 다운로드 단계에서 중단했다.
공식 이력과 조회 경로는 [version/README.md](version/README.md)에 정리했다.
XML에는 원문 페이지·좌표가 없으므로 XML 문단 근거를 표시할 수는 있어도
현재 PDF 화면의 OA 페이지 이동·하이라이트까지 동일하게 재현했다고 할 수 없다.
XML을 새 PDF로 출력하더라도 원본 OA PDF라고 표시해서는 안 된다.

## 4. 현재 코드에 실제 입력한 결과

[checks.json](checks.json)에 실행 결과를 기록했다.

| 확인 | 결과 |
|---|---|
| 확보한 5개 PDF 열기·텍스트 추출 | 성공: 각각 17 / 18 / 13 / 19 / 25쪽 |
| 현재 LocalAdapter로 대상 공개특허 PDF 읽기 | 성공: 17쪽, 한국어 문구 보존, OCR 미사용 |
| 현재 LocalAdapter로 의견제출통지서 XML 읽기 | 실패: PDF/TXT/JSON만 지원 |
| 현재 Claim parser로 한국 청구항 추출 | 실패: 한국어 `청구범위`, `청구항 1` 형식 미지원 |
| XML의 거절 이유 본문만 현재 OA parser에 전달 | 0개 추출: 한국어 거절 문장·한국 법조항 미지원 |
| 공개 청구항과 OA에 적힌 청구항 구성 비교 | 전제부·구성요소 8/8 일치, 표시 형식만 제외 |
| Azure 분석 | 실행하지 않음. 품질·수정안 정확도 검증 없음 |

재현(프로젝트 루트, 네트워크·LLM 호출 없음):

```powershell
uv run python data/research/kr_1020190000844/probe.py
```

`probe.py`는 이 자료만 비교하는 조사 도구다. 서비스에 한국어 parser를 추가한 것이 아니다.

## 5. 서비스에 필요한 변경 범위

| 부분 | 필요한 작업 |
|---|---|
| 문서 입력 | 한국 OA XML 어댑터, XML 요소와 원문 위치 연결. 한국 PDF 추출 품질 검증 |
| 청구항 분석 | 한국어 청구범위 시작·끝, `청구항 제N항`, 종속 표현 및 삭제항 지원 |
| 심사 의견 분석 | 한국어 거절 문장, 심사 대상/거절 대상 구분, 한국 법조항 추출. 안내문에 나온 법조항은 별도 취급 |
| 인용문헌 | 인용발명 번호와 한국 공개/등록번호 연결, 인용한 문단·청구항 연결 |
| Azure | 한국 문서용 프롬프트와 결과 검증 규칙 추가. 현 프롬프트 및 검증기는 USPTO/영어 중심 |
| 분석 이후 지원 | 명세서·인용발명의 관련 부분을 검색해 Azure가 차이점·대응 검토안을 작성하고 원문 근거와 함께 표시하는 별도 단계 |
| 화면 | 기존 Claim·사유·문헌 관계 화면을 재사용하되 국가별 법조항 표기, XML 근거 보기 지원 |
| 스캔 문서 | 현재 OCR `eng` 설정을 한국 문서에서는 `kor+eng` 등으로 지원하고 품질 검증 |

권장 흐름:

```text
한국 명세서/청구항 + 의견제출통지서 XML/PDF + 인용발명
→ 출원번호·문서 날짜·청구항 버전 확인
→ 한국어 구조 추출 및 원문 위치 기록
→ 청구항·거절 사유·인용발명 연결
→ 관련 명세서/선행문헌 부분 검색
→ Azure 문맥 비교·대응 검토안 생성
→ 원문 근거 확인·사용자 검토
```

처음에는 추가 모델 학습 없이 문서 근거를 입력하는 방식으로 시제품을 설계할 수 있다.
Azure를 연결하는 것만으로 한국어 parser 및 미국 기준 결과 검증 규칙이 바뀌지는 않는다.
청구항 수정안의 적절성은 이번 데이터 확보·텍스트 대조로 검증한 항목이 아니다.

## 6. 데이터 비용과 확대 가능성

- 이번 사건의 공개공보·인용발명 PDF 확보에는 구매비가 들지 않았다. OA는 사용자가 제공한 샘플이다.
- [KIPRIS Plus 의견제출통지서 학습데이터](https://plus.kipris.or.kr/portal/data/clasList/DBII_000000000000499/view.do?kppSCode=KPP010401&menuNo=210048)는
  1999~2022년, 2,871,807건(2025-04-29 기준), Python pickle, 무료로 안내한다.
  연구·비영리 목적과 출처 명시 안내가 있다. 상업 서비스의 이용조건을 확정한 것은 아니다.
- 그 상품을 실제로 내려받아 필드를 검사하지는 않았다. 설명만으로 심사 당시 청구항·명세서가
  모두 1:1로 포함된다고 판단할 수 없다. 이 사례의 문서 연결 성공을 전체 데이터에 일반화하지 않는다.
- [일반 의견제출통지서 상품](https://plus.kipris.or.kr/portal/data/service/DBII_000000000000242/view.do?menuNo=200101&subTab=SC003&entYn=N)은
  TXT/XML/PDF 및 API의 PDF 다운로드 주소를 안내한다. BULK 표시 가격은 당해연도 682,516원,
  과거 전체 3,753,835원이다. 청구항·보정 이력까지 검증된 세트 가격은 아니다.
- [공식 요금 안내](https://plus.kipris.or.kr/portal/use/paymentMmg.do?menuNo=210112)의
  API 월 1,000회 무료는 호출 수 기준이며 1,000건의 문서 세트를 보장하지 않는다.
  샘플 무료와 전체 상품 무료는 다르다.

현재 판단: **이 실제 한 쌍으로 한국 시제품을 시작할 수 있다.**
서비스 확대 전에는 여러 사건에서 청구항 버전 연결률, XML 필드 차이, 종속항·다중 거절 추출,
OA 원본 PDF 확보, Azure 출력의 근거 정확도를 추가 검증해야 한다.
