# 한국 실제 문서 회귀 라벨

2019년 KIPRIS 공개 샘플의 의견제출통지서 PDF/XML과 대응 공개특허 5건입니다.
원본은 `data/downloads/Patent_Review_KR_Data_20260917`에 있으며 각 JSON은
원본 경로와 SHA-256을 고정합니다. 출처 URL은 원본 배포 폴더의 `sources.json`을 참조합니다.
인용발명 추가 2개는 `references/*.source.json`에 다운로드 주소와 해시가 있습니다.

`claims`, `dependencies`, `rejections`, `statuses`는 원문을 읽어 작성한 라벨입니다.
자동 분석 결과를 정답으로 복사하지 않았습니다. `evidence`는 원본 PDF의 물리적 1-based
시작 페이지를 추가 대조한 라벨이며 단어 좌표의 정답이 아닙니다.
0902 청구항 6은 제목이 p.3에 있고 **본문 시작은 p.4**입니다.
0902 청구항 11–16은 p.1의 명시적 심사 대상 목록에 있으므로 pending이며 허용이 아닙니다.
이 상태의 초기 전사 수정은 해당 JSON의 `label_notes`에 기록했습니다.

| 출원 | 청구항 | 상위 거절이유 | 고유 인용발명 | 업로드 가능한 인용 원문 |
|---|---:|---:|---:|---:|
| 10-2019-0000844 | 1 | 1 | 3 | 3 |
| 10-2019-0000874 | 9 | 2 | 2 | 2 |
| 10-2019-0000902 | 16 | 1 | 0 | 0 |
| 10-2019-0000903 | 1 | 2 | 2 | 0 |
| 10-2019-0000948 | 9 | 4 | 1 | 0 |

0948 R1은 발명의 설명에 관한 거절로 청구항을 임의 할당하지 않습니다.
R3/R4의 같은 비특허문헌은 고유 문헌 하나로 유지합니다.
공개공보가 심사 당시 정확한 청구범위 버전인지 전체 보정 이력으로 확인하지는 못했습니다.
모든 사례의 `version_status`는 uncertain입니다.

실행: 프로젝트 루트에서 `uv run python -m scripts.validate_kr_parity`.
원본 해시·라벨·참조 연결·문자 위치·물리 페이지를 검사하고 실패 시 종료 코드 1입니다.
측정치는 `data/outputs/kr_parity/parser_metrics.json`에 저장합니다.
`prepare_kr_goldens.py`는 초기 수동 전사를 기록한 도구로 이미 동결된 JSON을 덮어쓰지 않습니다.
현재 확정 라벨은 이 디렉터리의 JSON이며 이후 추가한 페이지 전사를 포함합니다.

OCR fixture는 `scripts/validate_kr_ocr.py`가 별도 출력 폴더에 생성합니다.
이는 실제 공개 문서를 이미지로 변환한 자료이며 실제 스캐너 촬영물이라고 표시하지 않습니다.
원본 PDF는 변경하지 않습니다. 실제 사건/합성 보정 이력/파생 OCR/LLM 모의 응답을 구분합니다.
